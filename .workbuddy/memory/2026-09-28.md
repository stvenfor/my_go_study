### 切 Docker 的三个阻塞（都已解决）
1. **Docker Hub 不可达** → `~/.docker/daemon.json` 加 `registry-mirrors: ["https://docker.m.daocloud.io"]`（已备份为 `daemon.json.bak-20260928`），重启 Docker Desktop 后 `docker info` 显示加速器生效。
2. **brew PG/Redis 占 5432/6379** → plist 被移到 `~/Library/LaunchAgents/disabled/`（可逆），并 kill 进程。注意 postgres 真实路径在 `Cellar/` 而非 `opt/`，`pkill -f opt/...` 匹配不上。
3. **本地 `./bin/api` 占 8080/9090** → 杀掉。
