# 02 · 配置体系（Viper 加载链 / 结构体字段逐项 / YAML 差异 / 环境变量）

> 一句话定位：本篇讲清「一个配置值从文件或环境变量到 `cfg.xxx` 字段的全过程」，并逐个字段列出含义与默认值；所属模块为 common/config（叶子底座），消费方覆盖 app/cmd 全部六个入口；阅读前置：先读 [01-工程结构与go-work多模块](01-工程结构与go-work多模块.md)。

## 通俗理解：配置就像「默认菜单 + 便签改单」

想象点餐：

1. **config.yaml** 是印好的标准菜单（所有键的默认值）。
2. **config.dev.yaml / config.lan.yaml / config.prod.yaml** 是贴在菜单上的便签：只写「和标准不一样的几行」，由 Viper 用 Merge 机制叠加上去。
3. **环境变量** 是服务员现场听到的口头要求，优先级最高，覆盖同名项。
4. **supabase.env / .env / .env.local** 比较特殊：它们既被 shell `source` 进环境变量（走第 3 条路），又会被 `config.Load` 再读一遍，专门给「YAML 里不想写的密钥/团队常量」兜底。
5. 最后代码里还有一道**出厂默认值**检查：关键项为空或非法时由 Go 代码填回安全默认（比如队列名、SSE 限流、gRPC 端口）。

## 配置的消费方之一：common/logger

源码锚点：[common/logger/logger.go](file:///Users/qpy/Desktop/github/my_go_study/common/logger/logger.go)。通俗理解：logger 是一个「双水龙头」——同一条日志同时流向控制台（给人看，console 格式）和文件（给机器查，JSON + lumberjack 自动切文件）。

| 函数/变量签名 | 职责 | 备注/坑 |
|---|---|---|
| `var global *zap.Logger` | 包级单例 | 未 Init 时 L() 会懒建一个 production logger |
| `Init(cfg config.LogConfig) (*zap.Logger, error)` | 解析级别 → 建 consoleCore（stdout）→ cfg.File 非空时再建 fileCore（lumberjack 轮转 + JSON 编码）→ `zap.New(NewTee(cores), AddCaller)` 赋给全局 | 时间键名改成 `time`、ISO8601、级别大写；级别非法返回错误 |
| `L() *zap.Logger` | 取全局 logger | global 为 nil 时静默 `zap.NewProduction()` 兜底（注意吞错） |
| `Sync()` | 刷盘 | global 为 nil 直接返回；错误被忽略 |
| `parseLevel(level string) (zapcore.Level, error)` | debug/info/warn(warning)/error 映射；**其他值返回 InfoLevel + error** | Init 收到未知级别会启动失败 |

lumberjack 参数对应：MaxSize 单文件 MB、MaxBackups 保留旧文件数、MaxAge 保留天数、Compress gzip 压缩。

## 学习要点回顾

1. 加载优先级（从低到高）：config.yaml → config.<env>.yaml merge → 环境变量绑定 → supabase.env/.env 系列「只补空值」 → Go 代码默认值；唯一硬性必填是 `jwt.secret`。
2. APP_ENV 一鱼三吃：选环境 yaml、写入 `cfg.AppEnv`、参与「非正式环境」判定（IsLabAppEnv）；它和 gin 的 server.mode 是两条独立开关。
3. provider 空值有历史包袱：auth.provider 空按 supabase 走；sse/cs_agent 的 provider 空按 mock 走。
4. `PushAsync *bool` 是刻意的三态设计：nil（默认异步）、true、false（dev/lan 同步直投 WS）。
5. 密钥分两类管理：Supabase URL/anon_key 可入团队文件 supabase.env；service_role、SSE_OPENAI_API_KEY、各支付/IM Secret 只走 env/`.env.local`。
6. 结构体方法大量承担「默认值与归一化」职责，业务代码应只调方法（UseAsyncPush/ProviderName/WSURL…），不要直接读裸字段。
7. third_party 的 `*Configured()` 是装配期开关：极光/融云 key 含 PLACEHOLDER 视为未配置，API 仍可用但不真实下发。
8. logger 双 core Tee：控制台 console 编码、文件 JSON 编码；未知日志级别会让进程启动失败。
