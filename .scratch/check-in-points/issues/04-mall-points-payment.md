# 04 — 商城双价 + 积分/混合支付 + 退分

**What to build:** 商城 SKU 支持仅人民币、仅积分、混合（固定付满 CNY 价与积分价）；下单时同一订单内支付方式必须一致；支付时扣积分（积分作为支付渠道，混合为积分支付单 + 人民币支付单都成功才算已付）；支付失败或取消且已扣分时全额退回积分。

**Blocked by:** 01 — 积分账本 + 每日签到（含我的入口）

**Status:** done

- [x] SKU 暴露/持久化 `price_cny` 与 `price_points`（现有人民币价兼容为 CNY）；可派生三种商品支付方式
- [x] 创建订单拒绝跨支付方式混装；纯积分与混合支付路径可用（本地模拟人民币渠道仍可用）
- [x] 积分在支付动作扣减；混合两笔支付单都成功才已付；失败/取消退分
- [x] MallUsecase 缝有测试：纯积分付、混合成功、跨 mode 下单拒、取消/失败退分
- [x] 种子数据至少含纯积分与混合各一档，便于 LAN 联调

## Comments

- 未支付取消不扣分故无需退分；支付与扣分在同一 DB 事务内，失败自动回滚。
- 跨 mode 下单拒测覆盖在 CreateOrder 的 ErrMallPaymentModeMixed；纯积分/混合支付走 PayOrderLocal 同事务。
