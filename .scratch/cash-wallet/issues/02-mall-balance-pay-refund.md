# 02 — 商城余额支付 + 人民币退回钱包

**What to build:** 买家支付商城订单时可用余额作为人民币渠道（渠道码 6）；余额不足则整笔人民币支付拒绝；混合订单人民币腿可用余额、积分腿仍走积分。人民币已扣后取消或支付失败时，按 ADR-0015 全额退回钱包余额（含原以余额支付的单）。本票以 BFF + usecase 测试为主；Flutter 渠道选择留给 03。

**Blocked by:** 01 — 钱包账本 + 绑卡 + 充值 + Flutter 钱包页

**Status:** done

- [x] Mall 人民币渠道接受 `6`；支付时扣钱包；扣款发生在 pay 动作而非建单
- [x] 余额不足拒绝且不部分扣款；纯积分单拒绝用余额付积分价
- [x] 混合单：余额付 CNY 行 + 积分付积分行，两行都成功才算已付
- [x] 取消或人民币已扣失败 → 钱包入账（流水原因可区分 mall 退款）；其它 CNY 渠道取消同样退回钱包
- [x] MallUsecase（及必要的 Wallet 协作）自动化测试锁住上述行为
