# 02 — Flutter 购车计算器页接真报价

**What to build:** 买家（含游客）能从 App 可发现入口进入购车计算器：手填裸车价，切换全款/贷款，选择金融产品并填首付与期数，页面展示服务端返回的分项与合计（贷款含月供）。数字以 BFF 报价为准，不在本地另算一套当真相。本票不接方案保存、不接车型库、不做销售端当前店流程。

**Blocked by:** 01 — 种子金融产品 + 服务端全款/贷款报价 API

**Status:** done

- [x] 可发现入口进入计算器页（游客可进）
- [x] 拉取产品列表；全款/贷款切换；贷款可选产品、首付、期数
- [x] 提交后展示服务端分项与合计；加载与失败态不展示假数字
- [x] 校验错误（首付/期数等）有可读提示
- [x] 不实现「我的方案」落库；不依赖登录才能计算
