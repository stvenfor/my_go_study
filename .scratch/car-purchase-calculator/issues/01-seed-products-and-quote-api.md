# 01 — 种子金融产品 + 服务端全款/贷款报价 API

**What to build:** 平台目录下有 2～3 条可用金融产品；游客无需登录即可拉取产品列表，并提交裸车价（及可选计税价、首付、期数、产品）获得权威购车报价。全款与贷款均含 C-lite 分项（购置税法定近似、交强险固定额、商业险比例可关、贷款一次性手续费与厂商贴息）；贷款月供仅为等额本息。本票不接 Flutter UI、不落「我的方案」。

**Blocked by:** None — can start immediately

**Status:** done

- [x] `wys_` 金融产品表 + 启动种子 ≥2 条（含至少一条带贴息的示例）
- [x] 公开 `GET` 产品列表、`POST` 报价；无需 SessionAuth
- [x] 报价校验：未知产品、期数不在允许列表、首付低于最低比例、非正价格 → 明确 4xx
- [x] PurchaseQuote usecase 测试锁住：购置税默认与计税价覆盖、商业险开关、手续费、贴息、等额本息月供与利息合计
